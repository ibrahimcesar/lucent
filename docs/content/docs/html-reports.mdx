# HTML Reports Guide

## Interactive Code Analysis Reports

Lucent generates beautiful, interactive HTML reports with embedded visualizations, dark mode support, and export capabilities. These reports are perfect for sharing with teams, archiving analysis results, or viewing detailed metrics in a browser.

---

## 🚀 Quick Start

### Generate an HTML Report

```bash
# Analyze current directory and generate HTML
lucent . --format html > report.html

# Analyze specific directory
lucent src/ --format html > src-analysis.html

# Then open in browser
open report.html  # macOS
xdg-open report.html  # Linux
start report.html  # Windows
```

## 🔧 Advanced Features

### Dark Mode Persistence

```javascript
// Dark mode preference saved to localStorage
function toggleDarkMode() {
    const html = document.documentElement;
    const newTheme = currentTheme === 'dark' ? 'light' : 'dark';
    html.setAttribute('data-theme', newTheme);
    localStorage.setItem('theme', newTheme);  // Persists!
}
```

**Behavior:**
- Preference saved across browser sessions
- Per-domain storage
- Instant theme switching

## 📁 File Structure

The generated HTML report is structured as:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>💎 Lucent Code Analysis Report</title>

    <!-- Embedded CSS (~5KB) -->
    <style>
      :root { --primary: #9333ea; ... }
      /* All styles inline */
    </style>
  </head>

  <body>
    <!-- Report content (~10KB) -->
    <div class="container">
      <header>...</header>
      <section id="summary">...</section>
      <section id="charts">...</section>
      <section id="languages">...</section>
      <section id="smells">...</section>
      <section id="insights">...</section>
      <footer>...</footer>
    </div>

    <!-- Chart.js from CDN -->
    <script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js"></script>

    <!-- Embedded JavaScript (~5KB) -->
    <script>
      // All interactivity inline
    </script>
  </body>
</html>
```

**Total size:** ~20KB (without Chart.js)

## 🔐 Security Considerations

### Content Security Policy (CSP)

If hosting on a web server with strict CSP:

```html
<!-- Add CSP meta tag -->
<meta http-equiv="Content-Security-Policy"
      content="default-src 'self';
               script-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net;
               style-src 'self' 'unsafe-inline';">
```

### No External Data Transmission

- ✅ No analytics or tracking
- ✅ No external API calls (except Chart.js CDN)
- ✅ No form submissions
- ✅ All data stays local

### localStorage Security

- Data stored locally in browser
- Not transmitted over network
- Domain-scoped (isolated)
- Contains only theme preference

## 🎯 Best Practices

### 1. **Regular Generation**

```bash
# Add to CI/CD pipeline
.github/workflows/metrics.yml:
  - name: Generate HTML Report
    run: |
      lucent . --format html > report.html
  - name: Upload Artifact
    uses: actions/upload-artifact@v3
    with:
      name: quality-report
      path: report.html
```

### 2. **Archive by Version**

```bash
# Include version in filename
lucent . --format html > reports/v$(git describe --tags)-report.html
```

### 3. **Share Securely**

```bash
# Host on internal server
scp report.html internal-server:/var/www/reports/

# Or use GitHub Pages for public projects
mv report.html docs/index.html
git commit -m "Update quality report"
git push
```

### 4. **Combine with Other Formats**

```bash
# Generate all formats
lucent . --format html > report.html
lucent . --format json > metrics.json
lucent . --format csv > metrics.csv

# Use JSON for CI checks, HTML for humans
```

## 🐛 Troubleshooting

### Charts Not Rendering

**Problem:** Charts show as empty boxes

**Solutions:**
1. Ensure internet connection (Chart.js CDN)
2. Check browser console for errors
3. Try different browser
4. Disable ad blockers (may block CDN)

```html
<!-- If CDN fails, host Chart.js locally -->
<script src="/path/to/chart.js"></script>
```

---

### Dark Mode Not Persisting

**Problem:** Theme resets on page reload

**Solution:**
- Check if browser allows localStorage
- Try different domain/protocol
- Clear browser cache and cookies

---

### Print Layout Issues

**Problem:** Charts cut across pages

**Solutions:**
1. Use "Print/PDF" button (optimized)
2. Adjust print scale in browser settings
3. Try landscape orientation
4. Use "Save as PDF" instead of physical print

---

### Large File Size

**Problem:** HTML file is too large for email

**Solutions:**
1. Analyze subset of files
2. Compress with gzip before sharing
3. Host on web server instead
4. Use JSON format for data transfer

```bash
# Gzip compression
gzip report.html
# Reduces ~20KB to ~5KB
```
